📚 Estrutura de Dados I — Resumo
1. Conceito

Estruturas de dados são formas de organizar e armazenar informações para facilitar seu uso e processamento.

2. Principais estruturas
Array/Vetor: elementos armazenados em posições consecutivas, com acesso rápido por índice.
Lista: coleção de elementos que pode crescer ou diminuir dinamicamente.
Pilha (Stack): segue LIFO — o último a entrar é o primeiro a sair.
push → adiciona
pop → remove
Fila (Queue): segue FIFO — o primeiro a entrar é o primeiro a sair.
enqueue → adiciona
dequeue → remove.
3. Estruturas encadeadas
Lista encadeada: elementos são armazenados em nós, ligados por referências.
Lista duplamente encadeada: cada nó aponta para o próximo e o anterior.
4. Árvores

Estrutura hierárquica formada por nós.

Raiz: primeiro nó.
Filhos: nós abaixo de outro nó.
Folhas: nós sem filhos.
Árvore binária: cada nó possui no máximo 2 filhos.
5. Algoritmos

São sequências de passos para resolver problemas.

Busca: encontrar um elemento.
Ordenação: organizar elementos.
Exemplos: Bubble Sort, Selection Sort e Insertion Sort.
6. Complexidade

Mede o custo de um algoritmo em relação ao tamanho da entrada.

O(1): constante ⚡
O(log n): muito eficiente
O(n): linear
O(n²): mais lento para entradas grandes

Estrutura de Dados I estuda como organizar, armazenar, acessar e manipular dados de maneira eficiente.
